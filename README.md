# Makgahlela Attorneys Inc. — website redesign prototype

A responsive multi-page static website built using plain HTML, CSS and JavaScript. There is no build step or framework.

## Files
- `index.html` — homepage
- `services.html` — service descriptions
- `contact.html` — contact details and enquiry form
- `privacy.html` — privacy notice draft
- `disclaimer.html` — website disclaimer draft
- `styles.css` — layout, colours, typography and responsive styles
- `script.js` — mobile navigation, current year and email-draft form

## Open in VS Code
1. Download and extract the ZIP.
2. Open the `makgahlela-attorneys-website` folder in VS Code.
3. Open `index.html` in your browser, or install the Live Server extension and choose **Open with Live Server**.

## Important before publishing
This is a proposed redesign prototype, not a verified official website. The firm should approve the design and every page before launch. Confirm the full street address and map pin, telephone number, email, opening hours, current service availability, attorney names and qualifications, professional registration details, brand assets, privacy notice and disclaimer.

The enquiry form validates its fields and opens the visitor's email application with a draft. It does not send information to a server or store form submissions. For website-based submissions, connect a secure backend or reputable form service, configure spam protection and update the privacy notice.

Images and fonts are loaded from external providers and need an internet connection. Replace stock images with approved firm photography or appropriately licensed images before publishing. The monogram is a temporary text-based logo, not the firm's official logo.

No attorney biographies, awards, client testimonials, success rates or unverified street address have been invented. Have a South African legal professional review the disclaimer and privacy notice before publication.


## Official logo
The supplied Makgahlela Attorneys Inc. logo is saved unchanged at `assets/makgahlela-attorneys-logo.png` and used in the header/footer. The design palette follows the logo: black, gold/orange, red and white.
